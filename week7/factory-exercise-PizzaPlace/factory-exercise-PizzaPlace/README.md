# Factory Pattern Exercise

The Pizza store is a succes and we are branching out into other cities (Deventer, Enschede, Apeldoorn).

Each city will need to be able to have their own pizza's.

You need to write code for that. To make sure we end up with maintainable code you need to implement 
the Factory Method Pattern

## Steps

- Make sure the orderPizza method is no longer responsible for creating the pizzas
- Each city we branch into needs its own store
- Each store needs its own option for creating pizzas
